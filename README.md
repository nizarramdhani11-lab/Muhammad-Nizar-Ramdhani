# Muhammad Nizar Ramdhani — Portfolio

## Menjalankan website
1. Ekstrak ZIP.
2. Buka `index.html` dengan browser modern yang terhubung ke internet.
3. Untuk hasil terbaik, jalankan melalui local server (contoh: `python -m http.server 8000`) lalu buka `http://localhost:8000`.

## Teknologi
- HTML, CSS, JavaScript
- Three.js via CDN untuk pohon 3D prosedural dan interaksi drag/scroll
- Google Fonts via CDN
